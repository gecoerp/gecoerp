Select Products for Printing

After installation, the module allows label printing from any product list. Select one or multiple products and choose Print - Custom Product Labels to open the print wizard:

On the product page, label printing is available via the actions menu - Custom Product Labels:

To print labels from other Odoo documents, use the following extensions:

  • Maintenance Barcode Labels - labels for equipment and maintenance
  • MRP Product Labels - labels for products during manufacturing
  • MRP Workorder Labels - labels for components in work orders
  • Stock Product Labels - labels from stock operations (included in Odoo Label Builder Professional)
  • Purchase Product Labels - labels from purchase orders
  • Repair Product Labels - labels for repaired products
  • Sales Product Labels - labels from sales orders

Configuration

Replacing the Standard Print Wizard

To use this module via the Print Labels button, replace the standard Odoo print wizard:

Open the Settings — General Settings menu and in the Custom Labels section, enable the Replace Standard Print Wizard option:

Then, Save the settings.

Default Template Selection

A default label template can be assigned per user:

  • Open user settings
  • Select a user
  • In the Preferences tab, under the Custom Labels section, choose the default template

FAQ

Which Odoo objects and documents are supported for label printing?
Our label printing solution is built around a modular architecture. The core module provides the common label printing functionality for products, while optional extension modules add support for specific Odoo apps, such as Inventory, Manufacturing, Purchase, Repair, and others. Each extension enables label printing for the documents and objects of its corresponding Odoo app. For example, the Stock Labels extension supports printing labels for stock transfers, packages, locations, and other inventory-related records. This approach gives you maximum flexibility — you only install the extensions you actually need, without requiring unrelated Odoo modules to be installed in your Odoo database.

Do you provide assistance with this Odoo app installation?
Yes, if you are on Odoo.sh or use your own On-Premise hosting, and can grant us with access, we can help you with the installation and initial setup.

Can I install the module on Odoo Online (SAAS)?
No, Odoo Online is hosting where it is impossible to add any third-party module and install it. The Import module feature can't upload modules in a way that is required for their proper work.

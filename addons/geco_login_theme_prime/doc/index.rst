======================
GECO Login Theme Prime
======================

Overview
========
The **GECO Login Theme Prime** completely transforms the default, plain Odoo 18 login screen into a highly professional, modern, and engaging user interface. 
This module replaces the standard login page with a split-screen design, featuring an elegant glassmorphism card for the login form and a corporate hero section.

Key Features
============
* **Modern Design:** Utilizes CSS glassmorphism, smooth gradients, and Google Fonts (Inter & Outfit) for a premium look.
* **Split-Screen Layout:** A welcoming corporate message on the left, and a clean login card on the right.
* **Password Visibility:** Built-in eye icon to easily toggle the visibility of the password field.
* **Database Selector:** Redesigned and integrated seamlessly into the login card.
* **Fully Responsive:** Adapts perfectly to desktops, tablets, and smartphones.
* **Multilingual:** Native translation support (English, Spanish, French, Italian, and German).

Installation
============
1. Copy the `geco_login_theme_prime` folder to your Odoo `addons` directory.
2. Restart the Odoo service.
3. Enable **Developer Mode**.
4. Go to **Apps**, click **Update Apps List**.
5. Search for `GECO - Tema de Login Prime` and click **Install**.

Configuration
=============
No additional configuration is required. As soon as the module is installed, the login screen (`/web/login`) will automatically adopt the new theme.
If you have multiple databases, the redesigned database selector will appear automatically.
